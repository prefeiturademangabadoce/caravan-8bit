# Assets

**Art direction:** Salt-Scoured Field Manual — a true orthographic, isometric desert run using faceted geometry, simple sun lighting, a faded mineral palette, coarse low-resolution material detail, minimal dithered color steps, and weathered black expedition instruments. Signal Petrol (#2C7D88) indicates water and legitimate objectives; rust red signals cost, damage, danger, or route pressure.
